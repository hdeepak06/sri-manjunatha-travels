## 🚀 How to Run Locally

### Method 1: Direct in Browser
Double-click `index.html` to open it immediately in any browser (Chrome, Edge, Safari, Firefox).

### Method 2: Python Static Server
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.

## ✨ Features & Enhancements

- **Mobile-First Responsive Layout**: Meticulously designed and tested across 320px, 375px, 390px, 430px, 768px, 1366px, and 1920px viewports.
- **Luxury Gold Booking Buttons**: Sophisticated champagne-gold gradient with dark charcoal text and glowing elevation shadows.
- **Verified Business Information**: Accurate Hosapete HQ address, telephone, WhatsApp, 24/7 hours, and Google review search links.
- **Authentic Fleet & Office Showcase**: Real photographs of Sri Manjunatha Travels' Hosapete office counter, highway convoys, sanitized cabins, and wedding rental cars.
- **Interactive Leaflet Photo Map**: 12 verified Hampi landmarks on OpenStreetMap with custom photo pins, driving directions, and tour route line.
- **Dynamic Booking & WhatsApp Generator**: Interactive booking enquiry form with mobile validation, opening structured prefilled WhatsApp messages directly to dispatch.
- **WebP Image Compression**: Image payloads reduced by over 85% for blazing-fast mobile network loading without loss of visual quality.
- **Zero Framework Overhead**: Runs natively in any browser with no Node.js, Vite, React, or npm build steps required.
